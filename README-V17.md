# Chess Academy v0.17

Added teacher-managed weekly lesson goals, student/teacher weekly plan page, student-specific timestamped teacher feedback notes, last-seven-days quiz activity counts, and pending assignment suggestions.

**Limitations:** All accounts and notes are browser-local demo data, not a secure production multi-user platform. Seven-day activity is a rolling seven-day quiz count, not a historical weekly lesson completion count. Time tracking and video viewing are not verified server events. 100k puzzle ingestion is still pending.

Research: ChessKid teacher report cards and club features, Chess.com Classroom and guided lessons, Lichess puzzle dataset. Do not copy proprietary code or video lessons.
