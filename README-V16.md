# Chess Academy v0.16
Teacher analytics dashboard, student activity event log for quiz attempts and lesson completions, class/student CSV export, accessible clickable class roster report, student-specific guidance. Uses local demo storage only. Video views and puzzle totals are **not** fabricated. No backend or cross-device sync.
Research references: ChessKid report cards and classroom planner, Chess.com Classroom and lessons, Lichess CC0 puzzle database. Their proprietary code/content was not copied.
