# Chess Academy v0.19: Lichess Cloud Eval Arrow
In classroom.html, the teacher sees a translucent green arrow for Lichess cloud evaluation's top principal-variation move after changing a position. Fetches public `GET https://lichess.org/api/cloud-eval?fen=...&multiPv=3&variant=standard`. 800ms debounce, stale-response guard, in-memory cache, and automatic shutdown on HTTP 429. Validates returned UCI move against the chess engine before drawing. Honors board flip and teacher toggle. If no cached cloud evaluation exists (404), offers Lichess analysis board instead. This is NOT a locally running Stockfish engine, a live class sync, or a guarantee that a move is 100% best. Requires online access; browser CORS/network policies may prevent cloud fetch. Engine suggestions must not be used during rated live games.
